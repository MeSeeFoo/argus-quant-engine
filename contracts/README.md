# argus-contracts

Single source of truth for every message contract: SBE schemas for the fast path (Aeron) and Protobuf schemas for the durable path (Kafka).

The Maven module is added in [#4](https://github.com/MeSeeFoo/argus-quant-engine/issues/4) (SBE) and [#5](https://github.com/MeSeeFoo/argus-quant-engine/issues/5) (Protobuf).
